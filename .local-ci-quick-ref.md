# Local CI Quick Reference

## One-Liners

```bash
# Full CI run (like GitHub Actions)
./run-ci-locally.sh

# After editing seh64.inc (fast rebuild)
make -C rtl clean OS_TARGET=win64 CPU_TARGET=aarch64 && \
make -C rtl all OS_TARGET=win64 CPU_TARGET=aarch64 \
  FPC=/tmp/fpc_ci_runner/fpc_install/lib/fpc/3.3.1/ppcrossa64 \
  BINUTILSPREFIX=aarch64-w64-mingw32- \
  OPT="-FD/tmp/fpc_ci_runner/llvm-mingw/bin -dFPC_DEBUG_WIN64_UNWIND" && \
cd tests/phase2-tests && \
/tmp/fpc_ci_runner/fpc_install/lib/fpc/3.3.1/ppcrossa64 \
  -Twin64 -XPaarch64-w64-mingw32- \
  -Fu../../rtl/units/aarch64-win64 \
  -FD/tmp/fpc_ci_runner/llvm-mingw/bin \
  -a -oarm64trap.exe arm64trap.pas && \
grep -n "bl.*_FPC_local_unwind" arm64trap.s

# Clean everything
rm -rf /tmp/fpc_ci_runner && make clean && ./run-ci-locally.sh --clean
```

## File Locations

| What | GitHub CI | Local |
|------|-----------|-------|
| Workspace | `$GITHUB_WORKSPACE` | `$PWD` |
| Temp | `$RUNNER_TEMP` | `/tmp/fpc_ci_runner` |
| llvm-mingw | `$RUNNER_TEMP/llvm-mingw` | `/tmp/fpc_ci_runner/llvm-mingw` |
| FPC install | `$RUNNER_TEMP/fpc_install` | `/tmp/fpc_ci_runner/fpc_install` |
| ppcrossa64 | `compiler/ppcrossa64` | `compiler/ppcrossa64` |
| ppca64 | `compiler/ppca64` | `compiler/ppca64` |
| Test exes | `tests/phase2-tests/*.exe` | `tests/phase2-tests/*.exe` |
| Artifacts | GitHub artifact | `arm64-exes/` |

## Environment Variables (from workflow)

```bash
export FPC_VERSION="3.3.1"
export LLVM_MINGW_RELEASE="20251216"
export GITHUB_WORKSPACE="$PWD"
export RUNNER_TEMP="/tmp/fpc_ci_runner"
export PATH="/tmp/fpc_ci_runner/llvm-mingw/bin:$PATH"
```

## Workflow Steps → Local Commands

| Step | Command |
|------|---------|
| Install tools | `sudo apt-get install -y build-essential fpc` |
| Install llvm-mingw | `curl -sL <url> \| tar -xJ -C /tmp/fpc_ci_runner/llvm-mingw --strip-components=1` |
| Cross-install | `make crossinstall CPU_TARGET=aarch64 OS_TARGET=win64 ...` |
| Compile tests | `ppcrossa64 -Twin64 -XPaarch64-w64-mingw32- ...` |
| Build ppca64 | `make -C compiler compiler FPC=ppcrossa64 ...` |
| Disassemble | `aarch64-w64-mingw32-objdump -d arm64trap.exe` |

## Check Points

```bash
# ✓ ppcrossa64 exists
ls -lh compiler/ppcrossa64

# ✓ system.ppu has _fpc_local_unwind
strings /tmp/fpc_ci_runner/fpc_install/lib/fpc/3.3.1/units/aarch64-win64/rtl/system.ppu | grep _fpc_local_unwind

# ✓ Assembly has unwind call
grep "bl.*_FPC_local_unwind" tests/phase2-tests/arm64trap.s

# ✓ Test exe exists
ls -lh tests/phase2-tests/arm64trap.exe
```
